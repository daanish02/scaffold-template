## Intuition

A 2x2 matrix can be read as an instruction for moving every point in the plane at once - stretching, squashing, rotating, or flipping space. Some directions survive this move unchanged in orientation, only scaled: those are the interesting ones.

## Formal definition

For a square matrix $A$, a nonzero vector $v$ is an **eigenvector** with **eigenvalue** $\lambda$ if:

$$
Av = \lambda v
$$

For a 2x2 matrix, eigenvalues solve the characteristic equation $\lambda^2 - (a+d)\lambda + (ad - bc) = 0$.

<CodeCell lang="python">

```python
import numpy as np

A = np.array([[2, 0], [0, 1]])
values, vectors = np.linalg.eig(A)
print(values)
```

</CodeCell>

## Common pitfalls

<Callout label="Common pitfall">
  Not every real matrix has real eigenvectors - a rotation matrix, for example, has none (its eigenvalues are complex).
</Callout>

<Callout label="Common pitfall">
  Eigenvectors are only defined up to scale - any nonzero multiple of an eigenvector is also an eigenvector for the same eigenvalue.
</Callout>
